Every strategy uses its default parameters (the Backtest tab's parameters for the selected strategy), the same period and the same costs. The leaderboard is ranked by Sharpe ratio (risk-adjusted), not total profit.

Leaderboard

The parameter grid is searched on the training period only. The best parameters are then frozen and run on the test period they have never seen. A big drop in performance means the strategy was fitted to noise.

Top in-sample parameter sets

Re-optimise on a rolling training window, trade the next test window with those frozen parameters, then roll forward. Only the out-of-sample segments are stitched together, which gives the most honest estimate of live performance.

Windows

Each day is labelled using trailing data only, and each return is attributed to the regime known at the previous close. This shows when a strategy works and when it breaks.

Predicts whether tomorrow closes higher using 12 technical features. The model is retrained on a rolling window, and every prediction comes from a model that never saw that day, so accuracy shown here is genuinely out of sample.
